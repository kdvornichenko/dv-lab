## Spacing Scale

Declared values (all multiples of 4; Tailwind v4 step 4px):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between icon buttons in the top bar, title and description inside `Panel` / `PageHeader` |
| sm | 8px | Label to input, icon to label, avatar to name, button groups, top-bar right padding, horizontal padding of palette rows, reveal rows and `Input` (`px-2`) |
| md | 16px | Page side padding below 768px, page block gap and top padding below 768px, form field groups and dialog form field spacing, `Panel` header padding, panel padding in dialogs, skip link horizontal padding |
| lg | 24px | Page block gap from 768px, page top padding from 768px (`md:pt-6`), auth panel padding, dialog section gaps |
| xl | 32px | Page side padding from 768px (`md:px-8`) |
| 2xl | 48px | Vertical padding of `EmptyLine` and of the palette empty row (`py-12`) |
| 3xl | 64px | Bottom page padding (`pb-16`) so the last block is never covered |

Route used for the off-scale values of variant A: re-mapped to the declared scale, not declared as exceptions. A 12 → 8 (avatar gap, row padding) or 16 (panel padding, form spacing); 20 → 16; 28 → 24; 112 → 64. Hand-written and edited code uses only these tokens; copied registry components that are not edited keep their internal paddings (they are component dimensions, see below).

Exceptions (not spacing, component dimensions from the registry): control heights 28px (`compact`, `icon-compact`) and 36px (`default`, `Input`); icon size 16px, and 20px for the palette `Search` icon; badge 24px; top bar 48px (`h-12`); palette input row 48px; sidebar width 240px (`width="15rem"`, resizable 160–360px); dialog widths 400px (`sm`) and 540px (`lg`); auth panel `max-w-sm` 384px; table avatar 28px. No half steps (`0.5`, `1.5`, `2.5`, `3.5`) and no `3`, `5`, `7`, `28` step classes in new or edited code.

## Typography

Variant A screen scale [A, vault D-38], written straight into `:root` (no `.app-scale` class, dv-lab has no reading-scale pages to protect): `--fs-display: 22px; --lh-display: 28px; --fs-subtitle: 13px; --lh-subtitle: 20px;` on top of the lab `--fs-*` / `--lh-*` tokens. Sizes only through the role utilities `text-display|title|body|caption`; no `text-sm`, `text-xs`, `text-[13px]` in app code.

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Display | 22px (`text-display`, `tracking-tight`) | 600 | 28px | `PageHeader` `h1` ("Today", "Students"), `h1` on sign-in and on the student landing |
| Heading | 16px (`text-title`) | 600 | 22px | Dialog titles, brand name on auth screens, `Panel` titles |
| Body | 13px (`text-body`) | 400 | 20px | Field labels (muted), input text, descriptions, table cells, sidebar rows, palette items, buttons |
| Caption | 12px (`text-caption`) | 400 | 16px | Helper text, field errors, table secondary line (login), badge text, `⌘K` hint context |

Exactly four sizes (22, 16, 13, 12) and two weights (400, 600). Weight 600 is used by `h1`, dialog titles, `Panel` titles, initials in the avatar and the active row of lab components; the registry renders 600 as `font-variation-settings: 'wght' 550` internally, same role, not a third weight. Body line-height 20/13 ≈ 1.54, heading line-height 28/22 ≈ 1.27 and 22/16 ≈ 1.38 (A values, kept). Generated password: Geist Mono at `text-body`, weight 400.

## Interaction Contract

- **Keyboard.** ⌘K / Ctrl+K toggles the palette (`preventDefault`); ignored while another dialog (not the palette) is open (`document.querySelector("[role='dialog']:not([data-palette])")`); Esc closes and returns focus to the opener; arrows move the highlight, Enter runs. Tab order on the shell: skip link → trigger → search → section links → account row → page. Dialog focus: first invalid or first empty field on open (Name in create, Current password in change), Keep account in deactivate, "I saved the password" in reveal; focus is returned to the opener on close.
- **Theme.** Default follows the system. The toggle flips between light and dark from `resolvedTheme`; `aria-pressed` ("dark is on") is set only after mount to avoid a hydration mismatch; Light / Dark / System palette items call `setTheme('light' | 'dark' | 'system')`.
- **Pending and double submit.** While a request runs the submit button shows `loading` and is disabled, inputs are `disabled`; focus is restored to the first invalid field after a failure.
- **Hover, press, focus.** Registry components own their states (hover `bg-hover`, press `bg-active`, focus 1px ring). Hand-written rows use `hover:bg-hover focus-visible:ring-2 focus-visible:ring-focus-ring`.
- **Motion.** Registry defaults (Dialog scale 0.97 + fade, Banner, Tabs spring). With `prefers-reduced-motion` the registry's reduced-motion handling stays on; no custom animation is added.
- **Narrow widths (phone layout is phase 23, must not break).** Keep `variant={isMobile ? "sidebar" : "inset"}` and the drawer closing on navigation; page padding 16px; dialogs keep the registry `w-[calc(100%-2rem)]`; the accounts table scrolls horizontally inside its frame, the page never does down to 320px; long names and logins truncate with `truncate`, the landing `h1` wraps; auth panel keeps `px-4` page padding. Icon buttons stay 28px (A); touch sizing is revisited in phase 23.
- **Auth redirects.** `proxy.ts` only checks the cookie shape [D-02]; unauthenticated → `/login`, expired session → `/login?reason=expired`, signed in on `/login` → `/`.
