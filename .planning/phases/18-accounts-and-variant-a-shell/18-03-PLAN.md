- holdTestDatabase(env, options?: { waitMs?: number }): Promise<() => Promise<void>> — отдельный pg.Client под ролью migrator; set lock_timeout в waitMs (по умолчанию 600000, десять минут: чужой прогон успевает закончиться, зависший не держит вечно), затем select pg_advisory_lock(hashtext('dvlab_test_run')). Если ожидание превысило lock_timeout (код 55P03), клиент закрывается и бросается Error с текстом test database is busy. Возвращает release, которая делает pg_advisory_unlock с тем же ключом и закрывает клиента. Блокировка сессионная: если процесс упал, Postgres снимает её вместе с соединением.
- migrateTestDatabase(env): Promise<number> — runMigrations под ролью migrator.
- openTestDatabase(env): TestDatabase — { db: Database роли app, pool роли app, reset(): Promise<void>, close(): Promise<void> }; reset под ролью migrator читает select tablename from pg_tables where schemaname = 'public' order by tablename и, если таблицы есть, выполняет один truncate table с перечнем имён в двойных кавычках restart identity cascade (схема drizzle с журналом не трогается); close закрывает оба пула.
