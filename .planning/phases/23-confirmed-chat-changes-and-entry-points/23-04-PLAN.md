# 23-04 — Точки входа: палитра, Add payment, New chat, Ask in chat

<objective>
Сделать чат, оплаты и учеников доступными «в один шаг» (SHELL-04 и часть CARD-05): палитра находит учеников и предлагает New chat и Add payment, профиль предлагает Ask in chat. Всё строится на существующих владельцах: палитра `command-palette.tsx` на Base UI Autocomplete, ленивое создание разговора в `useChat` (`newChat`, создание первым Send), Add payment Today со своим чтением пояса, прибытие по параметрам адреса с их удалением (`withoutSearchParams`).

Запрос дизайна DR-23-05 (строки учеников палитры без `@handle`, место кнопки Ask in chat) отправлен ведущей сессией и не блокирует задачу: строится по SearchPalette README и 23-UI-SPEC §10.

Purpose: SC5 в части палитры и профиля.
Output: палитра, прибытие на Today и в чат, кнопка Ask in chat, проверка `entry-web.mjs`.
</objective>
