Контракты: `CHAT_CHANGE_OPERATIONS` дополняется `create_card`, `set_rate`, `archive_card`; варианты `change`: `create_card` `{ displayName, rateMinor | null, currency | null, lessonMinutes, noShowDeducts: true, timeZone: null, gender | null, duplicateName: boolean }`; `set_rate` `{ studentId, studentName, before: { rateMinor, currency }, after: { rateMinor, currency } }` (пары nullable вместе); `archive_card` `{ studentId, studentName, requestedDeletion: boolean, accountActive: boolean }` (используется в Task 2). `CHAT_STEP_TOOLS` + `propose_student`, `propose_rate`, `propose_archive`.

`change-cards.ts` (новый) экспортирует проверку ввода, превью и применение для трёх операций; `changes.ts` только диспетчеризует по `target.operation` в propose и confirm (как для оплаты) и хранит общий порядок: блокировка действия, проверка state, применение, перевод в applied/stale.

`create_card`: `display_name` после `normalizeDisplayName` обязано входить в текст учителя (без учёта регистра), иначе `name_not_in_message`; длина по `isDisplayNameLength`. `rate_text` (если есть) — дословно в тексте, `parseMoney(rate_text, currency)`; без валюты — `currency_required`. `lesson_minutes` — целое, его цифры есть в тексте, иначе `LESSON_MINUTES_DEFAULT`. Остальное — значения формы по умолчанию (`noShowDeducts` true, `timeZone`/`parent`/`level`/`goals` null). `gender` — только `female`/`male` или null. `duplicateName` — есть карточка с таким же именем без учёта регистра. Ввод проверяется `saveStudentRequest.parse`. Confirm → `createCard(tx, input, context)` в транзакции решения, `receipt { studentId }`; повтор — тот же блок, вторая карточка не создаётся.

`set_rate`: `rate_text` дословно + валюта (`null` → валюта карточки, нет — `currency_required`) или `clear: true` для снятия ставки; новая пара равна текущей — `no_change`. В guard — `cardRevision`. Confirm → `setCardRate(tx, studentId, after, guard.cardRevision, context)`; `changed` → stale `student_changed`.

Инструменты (`tools.ts`, strict): `propose_student { display_name, rate_text | null, currency | null, lesson_minutes | null, gender | null }`, `propose_rate { student_id, rate_text | null, currency | null, clear: boolean }`; описания говорят, что значения копируются из сообщения учителя, а записи нет до подтверждения. `receipt()` для `change_proposal` по операции: имя ученика и заметка «Nothing changes until the teacher confirms in the chat. Do not repeat amounts or numbers: the block shows them.»

`runs.ts` SYSTEM: «To add a new student call propose_student; to change a student's rate call propose_rate. Copy names, amounts and numbers exactly as the teacher wrote them. Never say the change is done: the teacher confirms it in the chat.» Строка про `open_page` перечисляет оставшиеся страницы: edit other profile details, vocabulary, settings.
