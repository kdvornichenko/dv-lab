# 23-07 — Удаления из чата: оплата, заметка или комментарий, конец серии

<objective>
Закрыть «deletions» из CHAT-05 поддержанными владельцами операциями: удаление одной оплаты (`deletePayment`), отзыв заметки или комментария (`retractStudentNote`, `retractLessonComment`), конец серии через журнал команд Google (`end_series`). Удаление ученика навсегда не существует — это архив из 23-05. Заодно отказ Keep у предложения календаря фазы 22 начинает сохраняться на сервере.

Executor model: opus.

Purpose: SC1 для удалений.
Output: модуль `change-deletions.ts`, инструменты `student_payments`, `propose_payment_delete`, `propose_entry_removal`, отмена серии из чата, сохранённый Keep, разделы проверок.
</objective>
