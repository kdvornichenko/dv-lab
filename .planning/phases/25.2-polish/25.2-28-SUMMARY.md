## Контракт для 25.2-29

```ts
type EventTextRun =
  | { kind: 'text'; text: string; bold: boolean; italic: boolean; underline: boolean }
  | { kind: 'link'; text: string; href: string; bold: boolean; italic: boolean; underline: boolean }
  | { kind: 'break' }
type EventDescriptionBlock =
  | { kind: 'paragraph'; runs: EventTextRun[] }
  | { kind: 'list'; ordered: boolean; items: EventTextRun[][] }
  | { kind: 'divider' }
calendarEventDetails: { …, description: string | null, descriptionBlocks: EventDescriptionBlock[], descriptionFormatted: boolean, … }
placeView(location: string | null):
  | { kind: 'address'; href: string; label: string }
  | { kind: 'text'; text: string }
  | null
```

`runs` и `items` непустые; `href` начинается с `http://`, `https://`, `mailto:` или `tel:` в нижнем регистре, без пробелов и управляющих символов. Пустой список блоков — строка описания не рисуется. `placeView` даёт `null` для `null`, пустой и пробельной строки; `text` — исходная строка без обрезки. `placeView.href` сохраняет регистр схемы как набран (`HTTPS://…`) и через `eventLinkHref` не проверяется: рисовать его напрямую. Фикстуры для браузера: `descriptionFixtures`, `placeFixtures`, `hugeFixtures`, `ZOOM_LINK`, `ZOOM_PLACE` из `scripts/dev-checks/event-description-fixtures.mjs` (модуль только с данными, без импорта api).

- **Fix:** проверка `hostile` сравнивает точный список href: `https://example.test`, `mailto:teacher@example.test`, `https://example.test/ok`. Схема безопасная, поведение совпадает с разбором URL в браузере.
