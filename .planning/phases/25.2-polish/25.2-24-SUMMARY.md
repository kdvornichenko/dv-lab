## Что построено (по README SettingsPrompts v102, дизайн v106 в выгрузке)

- Карточка Command prompts: заголовок, описание, строка `caption muted` о том, что правится только текст; на каждую команду блок: команда моноширинным, бейдж Default / Customised / Edited, строка о назначении, поле (132 px, растёт до 320 px, на 375 px 168 px), строка состояния и счётчик «N / 8,000», кнопки Restore default, Discard, Save.
- Состояния: Saved to your account. / Unsaved changes / Default text restored. Save to use it. / Saving… (поле read-only на 50%, кнопки выключены, Save крутится); ошибки: пустой текст, превышение предела («The prompt is N characters over the 8,000 limit.», счётчик destructive), сбой сохранения; конфликт 409 `precondition_failed` — warning-строка с Reload prompt, Save выключен, черновик сохранён; загрузка формами (название, строка и имена команд настоящие, бейдж, текст и статус — `Skeleton`); ошибка чтения одной панелью «Could not read the prompts.» с Refresh; тост «Saved».
- Restore default кладёт `defaultBody` в поле без сохранения; Save текста, равного `defaultBody` (после trim), отправляет `body: null` и возвращает бейдж Default.
- Карточка Privacy последней: заголовок, описание «What leaves the app when you use the assistant.», строка с иконкой info 16 px; только текст, без переключателя и ссылки; видна без подключения Google; на вкладке Google Calendar не повторяется (`calendar-card.tsx` не менялся).
