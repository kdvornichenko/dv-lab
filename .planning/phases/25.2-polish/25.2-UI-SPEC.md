## Rules for every UI plan

- Use components of variant A (`components/ui`, base-ui) as is; a missing element is requested from the Design dude before it is built (step "request from design" in the plan).
- Both themes, reduced motion, 375 px and 768 px as drawn; scroll containers use the fade classes.
- Acceptance is in the browser (built-in) with `scripts/dev-checks/*-web.mjs` where they exist; a UI change is not reported as working without a browser pass.
- After a plan, the list of closed code-sync numbers goes to the Design dude.
