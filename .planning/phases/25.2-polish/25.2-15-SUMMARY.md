## Как проверка убирает `PUSH_VAPID_*` из `--env-file`

Node с `--env-file` не перекрывает переменные, уже заданные в окружении процесса, и удалить переменную из файла через окружение нельзя. Поэтому раздел `config` запускает второй api (порт 4272) без `--env-file`: читает `.env.test` через `parseEnv`, убирает из него и из `process.env` три `PUSH_VAPID_*` (и `MIGRATOR_DATABASE_URL`) и передаёт результат окружением процесса, добавляя нужный набор push для случая (ничего, неверный subject `http://localhost`, только публичный ключ). Файлов с секретами при этом не создаётся. Основной api проверки (порт 4271) запускается `startApi` из `api.mjs` с `--env-file=.env.test`, то есть с парой.
