## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| push-сервис → service worker | содержимое уведомления |
| уведомление → переход | адрес из данных push |
| неавторизованный запрос → manifest и sw.js | файлы отдаются без cookie |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25.2-45 | Spoofing (open redirect) | notificationclick | medium | mitigate | `url` принимается только как путь своего origin (начинается с `/`, не `//`), иначе `/`; адреса строит сервер из фиксированных слов и id |
| T-25.2-46 | Information disclosure | исключения proxy | low | mitigate | без cookie открыты только `sw.js`, `manifest.webmanifest` и четыре иконки по точным именам; данных в них нет |
| T-25.2-47 | Information disclosure | публичный ключ VAPID | low | mitigate | ключ приходит с api, в сборку web не вшивается (`NEXT_PUBLIC_*` нет) |
