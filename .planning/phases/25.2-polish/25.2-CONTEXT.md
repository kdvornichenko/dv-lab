## Locked Decisions (owner, 2026-10-14)

- **D-01 Design is closed:** v96-v101 (code-sync 76-111). Design dude tracks status by item number; after each plan send him the closed numbers. Two items are being redrawn by him: the replace-text card for notes (Confirm/Decline) and the Students ring (infinite).
- **D-02 No hard delete:** schedule rows change status or `ends_on` only. For notes: words of the vocabulary are kept 30 days in Removed, then erased; empty blocks may be deleted at once; a block with text is deleted only after confirmation. Migrations only add (`student_sections.kind` check is dropped by an additive release step; free block names, order).
- **D-03 Testing:** no new unit or e2e tests; acceptance by dev-check scripts, logs and the browser. Live Google writes only on the owner test account.
- **D-04 Runtime:** Claude only. Server through Server guy, design through Design dude.
- **D-05 Lesson duration:** a held lesson takes its duration from the calendar (current length in the schedule), not frozen at the mark. Held lessons are not moved or changed. Marks stay manual; card status changes only manually.

### Dialogs, skeletons, leftovers
- **D-10 Two dialog kinds (item 67):** asking dialogs have no corner X (footer Discard changes / Cancel then the action), showing dialogs have a corner X and no footer Close. Covers LessonDialog, EventDetails, PaymentDialog, NewLessonDialog, EventEditor, StudentForm and the library X dialogs.
- **D-11 ViewTransition for SkeletonSwap is kept:** no animation under reduced motion, no slide between sections.
- **D-12 Unbuilt design items** from the scout check (2026-10-12, re-verify at planning): 24, 37/57, 56, 52, 60/61, 62, 63, 26, 31, 19, 3 (see notes, "Сверка дизайна с кодом").
- **D-13 Widths:** long titles never widen a dialog or push a counter/Copy off (v93): `min-w-0` on every flex/grid ancestor, `truncate` with full text in `title`; check mention list, model rows, chat list.
- **D-14 Firefox fade:** `scroll-fade`, `scroll-fade-x`, `scroll-divider` need a fallback without `animation-timeline` (JS scroll position class + mask), same look, everywhere.
- **D-15 Small chat fixes:** effort chip text is off-centre on Y; Show steps chevron wraps under the text; effort popover title is live while dragging and the value (and chip) applies on release.

### Chat
- **D-20 Composer:** quick buttons Was / Didn't happen / No-show / Moved to… removed; assistant Suggestions chips removed; placeholder "Type / for commands or @ for a student"; bottom hint reduced to "Shift+Enter — new line", hidden on touch. The "Suggestions" block in facts and the `suggest` progress step are removed.
- **D-21 Facts block:** layout v94 (item 69); an answer that is a block has no assistant sentence and no Copy reply; one follow-up button "Count lessons since the last payment" sends at once and disappears from that answer; not drawn for a student without a payment; result is the existing dates block with Copy dates.
- **D-22 "Since last payment" boundary:** starts at the first lesson of the debt series before the last payment (lessons since the balance was last non-negative), else at the payment day inclusive; same pass as `studentBalance`; included: Done and No-show that deducted minutes.
- **D-23 Calendar search tool:** read-only; gives the model title, date, time and length (no description); search by title only; range up to ~400 days; built on the Google range read route from PR 39; a privacy line in Settings says event titles go to the model provider; sync window is not widened.
- **D-24 Card details from chat:** one tool edits Details fields (Rate, Lesson length, No-show, Gender, Parent, Level, Goals, Time zone), several fields in one Confirm/Decline card (`ChangeCardDetails`), `expectedRevision` CAS; Name, Status, account and Opening balance are not editable; out-of-list gender/time zone is clarified in chat; Level is free text.
- **D-25 Notes and vocabulary from chat:** the server decides by diff: new text that keeps every old line and only adds is written at once with a receipt and Undo; any removed, changed, merged, moved line, whole replacement, shortening or clearing gives an "Update <block>?" Confirm/Decline card; a new block when none fits is written at once; vocabulary words and empty blocks are removed at once with a receipt (Undo = Restore); the agent does not rename or reorder blocks; money, lessons and card facts always ask.
- **D-26 Review of notes and vocabulary:** per-student review date; the agent fixes duplicates and typos itself and reports conflicts in the result with one shared Undo; old "Added notes" are merged by the first review. The offer is asked once per chat as a separate message when notes come up, only if the last review was 14 or more days ago or notes changed, at most once a day per student; "Review now" in the profile opens a chat with the review already running.
- **D-27 Commands in the database (partial):** only the prompt text of built-in `/recap` and `/essay` moves to the database and is editable in Settings; the essay turn mode (read-only, strict `essay_feedback`, "Approximate estimate") stays in code. `/today`, `/tomorrow`, `/payments`, `/note` stay composer text. The builder and `/edvibe` belong to 25.3.

### Students and profile
- **D-30 Students table:** columns Student, Rate per lesson, Balance in lessons, Next lesson (Status removed); short balance form ("7 left", "owes 2", "0 left", "Not set") only in the table via a `short` option of `balancePhrase`; sorting and filters in the URL (nuqs), client-side `collectionView`-style pure function, sort cycle starts ascending, empties last; filters Payment / Currency / Rate / Next lesson with counts; no F hotkey; plenty has no dot; pays_soon is amber everywhere.
- **D-31 Ring:** the ring around the balance dot pulses infinitely while the state holds (pays_soon 3.0 s, none_left 2.2 s plus static ring, owes 1.6 s), starts 300 ms after rows appear, not restarted by sort, filter or refetch (key = student id); reduced motion has none; no WCAG pause (personal project, owner decision). DueList and the profile hint keep the finite v96 pulse.
- **D-32 Lessons tab:** date range with presets (Since last payment default, This month, Last 30 days, Custom); held dates block on top with Copy dates; table Date, Time, Outcome, Duration, Payment, Balance after; Outcome filter with counts and period totals; actions through LessonDialog (mark, move, cancel, restore, open in calendar); held lessons are view only; no New lesson; no comment-count badge.
- **D-33 Overview and Payments:** Opening balance moves to Payments as a row above the payments list with inline edit; Overview shows three facts, held dates with Copy, recent notes and comments, vocabulary; Details and Account on the right; Account stays on Overview.
- **D-34 Notes UI:** Add block, rename in place (max 60 chars, unique per student), delete with confirmation when it has text, drag/keyboard/menu ordering; all six standard blocks are ordinary and deletable; a new card gets all six; every block write carries the block revision (409 on stale); reviewed-date line at the top of Notes and Vocabulary.

### PWA and push
- **D-40 Installable PWA, no offline.** Push: "a lesson starts soon" (minutes before, 5-120, default 30, stored in Settings) and "a student is about to pay" (once when the Pays soon threshold is reached); debt and sync failures are not pushed. A tap opens Schedule on the lesson or the Payments tab. No notification while the app is in the foreground on the relevant screen. Settings: "Notifications on this device" and "What to notify about" (design 109-111).
