# 25.2-09 — Api: правка Details из чата, поиск по календарю, промпты /recap и /essay

<objective>
Три возможности чата поверх реестра 25.2-07: правка полей Details одной карточкой подтверждения (D-24, CS-91-92), поиск событий Google по названию и датам только для чтения (D-23; нормализация Count lessons из core — ограничение ARCH-A4; поля время и длительность — ARCH-A5), тексты встроенных `/recap` и `/essay` в базе с правкой через настройки (D-27). Плюс api-часть хвоста CS-52: фраза «This record cannot be removed in chat. Review its available actions in the existing screen.» со ссылкой Open record через существующий `open_page`.

Контракт: новая операция `set_details` расширяет `ChatChange`, которую `change-proposal.tsx` разбирает исчерпывающе; план добавляет туда ветки по умолчанию (общий текст без карточки полей), чтобы web-typecheck параллельного 25.2-10 оставался зелёным; карточку ChangeCardDetails строит 25.2-12. Строка приватности поиска по календарю и редактор промптов — web 25.2-12.

Решения по своему усмотрению: пояс в правке Details принимается только IANA-идентификатором (подпись «город (UTC+N)» строит web по `time-zones.ts`), неузнанное название — вопрос в тексте без карточки; ставка одной правкой остаётся `propose_rate`, а несколько полей или поля кроме ставки — `propose_details`. В 25.2 разрешены только команды `/recap` и `/essay`.

Executor model: opus (запись карточки из чата, внешний календарь, промпты хода).

Purpose: учитель меняет данные ученика и находит события календаря словами в чате, а тексты команд правит без изменения кода.
Output: `setCardDetails`, `set_details`, `propose_details`, `calendar_events`, `prompts.ts`, маршруты промптов, разделы проверок.
</objective>
