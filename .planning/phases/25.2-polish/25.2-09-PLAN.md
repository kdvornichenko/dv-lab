# 25.2-09 — Api: правка Details из чата и фраза CS-52

<objective>
Правка полей Details из чата одной карточкой подтверждения поверх реестра 25.2-07 (D-24, CS-91-92). Плюс api-часть хвоста CS-52: фраза «This record cannot be removed in chat. Review its available actions in the existing screen.» со ссылкой Open record через существующий `open_page` — она стоит здесь, потому что это та же строка отказа `SYSTEM`, которую переписывает Task 2.

Первая часть исходного плана 25.2-09. Исходный план нёс три независимые темы; он разделён по темам: поиск по календарю из чата — 25.2-20, тексты `/recap` и `/essay` в базе — 25.2-21. Этот план первым добавляет инструмент после реестра, поэтому сверка списка инструментов в `chat-runs.mjs` переводится на реестр здесь, и 25.2-20, 25.2-11, 25.2-13 этот участок не правят.

Контракт: новая операция `set_details` расширяет `ChatChange`, которую `change-proposal.tsx` разбирает исчерпывающе; план добавляет туда ветки по умолчанию (общий текст без карточки полей), чтобы web-typecheck параллельного web-плана (25.2-19 в волне 5) оставался зелёным; карточку ChangeCardDetails строит 25.2-23.

Решения по своему усмотрению: пояс в правке Details принимается только IANA-идентификатором (подпись «город (UTC+N)» строит web по `time-zones.ts`), неузнанное название — вопрос в тексте без карточки; ставка одной правкой остаётся `propose_rate`, а несколько полей или поля кроме ставки — `propose_details`.

Executor model: opus (запись карточки из чата).

Purpose: учитель меняет данные ученика словами в чате, а запись происходит только после его подтверждения.
Output: `setCardDetails`, `set_details`, `propose_details`, правило промпта и фраза CS-52, сверка инструментов с реестром, раздел `chat-changes details`.
</objective>
