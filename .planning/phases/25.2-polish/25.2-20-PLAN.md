# 25.2-20 — Api: поиск по календарю из чата

<objective>
Поиск событий Google по названию и датам из чата только для чтения (D-23; нормализация Count lessons из core — ограничение ARCH-A4; поля время и длительность — ARCH-A5) поверх реестра 25.2-07 и маршрута чтения диапазона Google из PR 39. Окно синхронизации не расширяется.

Вторая часть исходного плана 25.2-09 (разделён по темам: правка Details и CS-52 — 25.2-09, промпты `/recap` и `/essay` — 25.2-21). Строка приватности поиска по календарю в Settings и слово шага «Searching the calendar» — web 25.2-24 и 25.2-23.

Решение по своему усмотрению: поиск принимает пояс только IANA-идентификатором (из настроек учителя); фильтр по названию идёт на сервере через `nameMatches` из core, а не через Google `q`, который ищет и в описании.

Executor model: opus (внешний календарь, контекст модели).

Purpose: учитель находит события календаря словами в чате, а модель видит только название, дату, время и длительность.
Output: поля `end`, время и длительность в `eventTitleItem`, инструмент `calendar_events`, строка промпта, проверки `event-titles-api.mjs`.
</objective>
