## Маршрут GET /students/:id/lessons (под `requireSession`, `requireRole('teacher')`, `noStore`, чтение в `readSnapshot`)

- Запрос: `range=since_payment` либо `from` и `to` (`YYYY-MM-DD`, `to >= from`, не больше 366 дней). Иначе 400 `invalid_request` (367 дней, обратный порядок, один `from`, `range` вместе с днями, неизвестный `range`, несуществующая дата). Нет карточки или неверный id — 404.
- Ответ `StudentLessonsResponse`: `studentId`, `from`, `to`, `clipped`, `coverage` (`complete` | `partial` | `unread`), `asOf`, `defaultTimeZone`, `defaultLessonMinutes`, `lastPayment` (`{ id, paidOn, amountMinor, currency, creditedMinutes } | null`), `sinceLastPaymentFrom`, `lessons[]`, `totals` (`planned`, `done`, `noShow`, `cancelled`, `moved`, `heldCount`, `heldMinutes`).
- Урок `StudentLesson`: `key`, `ref`, `date` (день по 02:00 в главном поясе), `startsAt`, `timeZone`, `durationMinutes` (текущая длина в календаре), `outcome`, `movedFrom`, `movedTo`, `actions` (флаги блока недели), `mark`, `markRevision`, `counted`, `deductedMinutes`, `balanceAfterMinutes` (null — прочерк), `projected`, `payment` (`{ id, paidOn, amountMinor, currency, paidAfter } | null`), `held`, `sinceLastPayment`.
- Уроки идут по возрастанию времени; порядок «новые сверху» и линию Now строит web.

## Follow-up (25.2-12 копирует этот формат)

Кнопка отправляет обычное сообщение: `text` = `@<displayName> Count lessons since the last payment` (константа `CHAT_FOLLOW_UP_TEXT` после токена упоминания), `mentions` = `[{ studentId, text: displayName, start: 1, end: 1 + displayName.length }]`. Сравнение: из текста вырезается упоминание (с `@`), затем NFC, схлопывание пробелов, trim, нижний регистр; совпадение с той же нормализацией константы и ровно одно связанное упоминание. Ответ: одно сообщение ассистента с пустым `body`, одним блоком `lesson_dates` (`scope: 'since_payment'`, `from`, `to`, `sinceFrom`, `lastPaidOn`, `dates`), шагом `{ tool: 'lesson_dates', state: 'done', studentId, studentName, from, to }`, `turn: null`; ход модели, допуск по бюджету и попытки расхода не создаются. Без упоминания, с двумя упоминаниями или с лишним текстом — обычный ход.

Блок фактов несёт `followUp: 'since_payment'` только при `lastPayment` у карточки.
