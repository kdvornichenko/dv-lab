# Phase 25.2 Plan 09: правка Details из чата и фраза CS-52 Summary

Чат предлагает правку одного или нескольких полей Details одной карточкой Confirm/Decline через инструмент `propose_details`; запись идёт только после подтверждения через `setCardDetails` с ревизией карточки, изменившаяся карточка даёт `stale student_changed`. Промпт отказывает с `open_page` только для настроек, словаря, имени, статуса, аккаунта и Opening balance, на удаление записи без инструмента отвечает фразой CS-52; `chat-runs.mjs` сверяет инструменты с реестром.
