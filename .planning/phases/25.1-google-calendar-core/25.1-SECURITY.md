## Trust Boundaries

| Граница                                      | Данные и защита                                                                                                             |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Интернет → `POST /api/google/notifications`  | без сессии; id канала (UUID) и токен канала, сверка SHA-256 за постоянное время, меняется только `requested_seq`            |
| Браузер учителя → `/google/*`, `/schedule/*` | сессия, роль `teacher`, `no-store`, проверка Origin для небезопасных методов, ресурсы ищутся в текущем подключении аккаунта |
| Google → проекция `google_calendar_events`   | zod-разбор, пропуск плохих элементов, обрезка описания и места, только минимальные поля                                     |
| Проекция → уроки (inbound apply)             | только сопоставленные сущности подключения, отмеченные и прошедшие заморожены, без удалений                                 |
| api → Google (запись)                        | If-Match по etag строки, повторное чтение цели перед отправкой, сверка ответа                                               |
| Роль `dvlab_app` → Postgres                  | DELETE только на `google_calendar_events`, TRUNCATE нет ни на одной таблице фазы                                            |
| Журналы Caddy и api                          | токен канала и URI ресурса удаляются в обоих журналах Caddy; api пишет метод, путь, статус и счётчики                       |
| Публичный репозиторий                        | синтетические данные, только имена переменных и пути                                                                        |

## Проверка по направлениям

1. Вебхук push. Токен канала сравнивается как SHA-256 через `timingSafeEqual` (`google-notifications.ts:14-18`). Подмена канала невозможна без секрета: поиск по UUID, хеш своего канала (`sync-store.ts:124-135`). Отставленные и отключённые подключения отсекаются соединением с `currentConnection` (`sync-store.ts:47-53`), колонки каналов очищаются при смене и отключении (`sync-store.ts:101-122`). Старый канал при продлении теряет хеш и получает 404. В журнал api не попадают заголовки и query (`request-context.ts:64-71`), Caddy удаляет `X-Goog-Channel-Token` и `X-Goog-Resource-Uri` в обоих журналах (`Caddyfile:8-9`, `:34-35`). `X-Goog-Channel-ID` и `X-Goog-Resource-ID` остаются в журнале Caddy; без секрета и OAuth-токена они бесполезны.
2. Маркер Assign. Маркер читается только из `extendedProperties.private` (`provider-events.ts:189-192`), значения shared и приглашений внешних организаторов не учитываются. Принятие маркера требует сопоставления того же аккаунта (`assign.ts:112-117`, `event-mapping.ts:218-221`), разделение серии — серии того же подключения (`inbound-apply.ts:115-126`). Остаток — F-04.
3. Входящее применение. Несопоставленное событие возвращает `unchanged` (`inbound-apply.ts:443`). Удалений и записей в `lesson_marks` нет; отмена — статус или исключение, конец серии — `ends_on`. Прошедшие и отмеченные вхождения заморожены. Права БД (`REVOKE DELETE` на уроках, сериях, исключениях и отметках в прежних миграциях) остаются вторым рубежом.
4. Права БД. Подтверждено T-25.1-01.
