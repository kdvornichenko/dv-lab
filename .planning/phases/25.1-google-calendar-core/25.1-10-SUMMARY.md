# Phase 25.1 Plan 10: перенос и растяжение мышью, область при Save, подсказка имени Summary

**Любое обычное событие со временем и любой урок, который можно менять, переносятся мышью и растягиваются за нижнюю кромку на сетке 15 минут; отпускание только открывает форму (событие или Move lesson с полем Length), область для члена серии спрашивается при Save, а подсказка имени получила точку, строку в подсказке, плашку Assign и Ignore и ручной Assign.**

## Сверка дизайна v53 и v55

План писался по v53, исполнялся по v55 (`~/dv-lab-design`, VERSION v55; предусловие выполнено). Отличия, по которым сделано по v55:

- область для члена серии спрашивается при нажатии Save в форме, которую открыло отпускание, а не при самом отпускании (в v53 EventDrag область шла сразу);
- для урока три строки (This lesson, This and following lessons, All lessons) и подпись про прошлые уроки и отметки; для события три строки; для отмены урока две;
- форма Move lesson получила поле Length (HH : MM): растяжение заполняет Length и не трогает дату и время, перенос — наоборот;
- растяжение за нижнюю кромку есть в v55.

Отсутствующих элементов, на которых пришлось бы остановиться, не нашлось, кроме одного (см. отклонение 4).

## Что сделано

- **Перенос (`use-lesson-drag.ts`).** Тип `MoveSeed = SlotFrame & { gesture: 'move' | 'resize' }`. Нажатие в полоске растяжения перенос не начинает. Проверка «начало в будущем» только для урока (`binding.kind === 'lesson'`); обычное событие переносится в любое время. `up()` передаёт `{...seed, gesture: 'move'}` и ничего не сохраняет. `useEdgeScroll` вынесен для обоих жестов.
- **Растяжение (`use-event-resize.ts`).** Жест только от полоски `[data-slot="calendar-event-resize"]`; конец привязывается к 15 минутам, зажат в `[начало + 15, 1440]` (день урока 02:00-02:00, D-09); отпускание вне тела сетки или на исходной длине отменяет; Esc отменяет.
- **Сетка (`week-grid.tsx`, `lesson-block.tsx`).** Один `live = moving ?? resizing`, рамка с подписью времени (дата показывается, когда день сменился; для растяжения только диапазон), полоска растяжения высотой `min(8, высота/3)`, точка подсказки у блока с `suggestion`, призрак обычного блока без текста.
- **Экран (`schedule-screen.tsx`).** `canMove` (урок: `canEditCalendarEvent`, не отменён, в будущем; обычное событие: `canEditPlainEvent`), `studentName(id)`, список учеников загружается заранее, если в неделе есть подсказки.
- **Событие (`calendar-event-details.tsx`, `event-form.tsx`).** `CalendarEventDialog` принимает `moveSeed`: форма засевается на первом чтении деталей, различия считаются от базы события; `unsupported` (правило не weekly) допускается при переносе и даёт форму «только время». Плашка подсказки, ручной Assign «Not a lesson / Assign…», тосты «Event assigned» и «Suggestion dismissed».
- **Подсказка (`event-assign.tsx`, `event-tooltip.tsx`).** `SuggestionBox` (группа «Name match», «Looks like {name}'s lesson.», строка области «Applies to this event.» или «Applies to this series.», Assign и Ignore, состояния «Assigning…» и «Ignoring…», сообщение об отказе, состояние «изменилось в Google» с Refresh); `ManualAssign` с поиском учеников; в подсказке блока строка «May be {name}'s lesson. Click to assign.».
- **Урок (`lesson-move-form.tsx`, `calendar-lesson-dialog.tsx`).** Поле Length, перенос и растяжение засевают форму; `ScopeDialog` `{subject: 'lesson', action: 'save'}` подключён (был построен в 25.1-08, не вызывался); область `one` — `mutate` (вхождение или одиночный урок, `durationMinutes` при смене длины); `following` и `all` — `MoveSeriesDialog` с засеянными днём, временем и длиной. В `schedule-mutations.ts` `durationMinutes` в теле переноса, действие `assign`, `ignoreEvent`.
- **Серия (`move-series-dialog.tsx`, `move-series-preview.ts`).** Тип `SeriesSeed`, поле Length (показывается при засеве), `durationMinutes` в предпросмотре через `cutSeries` и в теле запроса, только когда длина изменена.

## Отклонения от плана

### Исправлено по ходу

**1. [Правило 1] Ignore идёт мимо `mutate`.** План говорил о мутации; api отвечает на `/ignore` кодом 204 без команды, поэтому вызов `ignoreEvent` (`apiRequest`) вне `useScheduleMutation`, затем `controller.readWindow(day)`. Коммит 290132e.

**2. [Правило 1] После Assign диалог закрывается.** Неделя перечитывается раньше, чем `mutate` возвращает результат, блок становится уроком, `SelectedEventDialog` подменяет диалог на урок, `mutate` возвращает `detached` и тост с закрытием не срабатывают. Теперь `detached` закрывает диалог. Коммит 5961207.

**3. [Правило 1] Окно проверки пересечений серии.** `MoveSeriesDialog` читал окно по сегодняшней неделе, а версия серии в нём может отсутствовать (серия начинается позже, урок перетащен в следующую неделю): проверка давала «Check failed. Retry», а `mutate` после проверки возвращал `precondition_failed` (окно не той недели) и закрывал диалог. При засеве окно берётся по `seed.from`. Без засева (кнопка Move series из деталей урока будущей недели) поведение прежнее. Коммит 5961207.

**4. [Нет в дизайне] Поле Length в `MoveSeriesDialog`** показывается только при засеве из переноса или растяжения; в v55 Move series его нет. Нужно показать Design dude.

**5. Текст «Could not dismiss the suggestion. Try again.»** для отказа Ignore придуман (в v55 нет); в паре с «Could not assign this event. Try again.» из исходной формулировки отказа.

**6. Строка урока с маркером без активного сопоставления** (`binding.kind = 'lesson'`, `editBlock = 'history_only'`) открывает диалог урока и повторный Assign не получает: `GET /google/events/:eventKey` для неё отдаёт `read_only_event`. Расхождение из SUMMARY 25.1-09 не закрывалось.

**7. Известное ограничение серверной проверки пересечений.** Сервер считает длину урока по сохранённой (замечание 25.1-07), поэтому у растянутого урока пересечения пересчитываются не по новой длине; клиент передаёт `durationMinutes` в предложение и в показ.

**8. Удаление одного вхождения не weekly серии из деталей** по-прежнему закрыто в 25.1-08 (`canDelete` требует `!unsupported`); перенос одного вхождения такой серии (D-16) работает.

**9. Подсказка по списку учеников.** `useLessonStudents` загружается заранее, когда в неделе есть подсказка, иначе в плашке и подсказке не было бы имени.
