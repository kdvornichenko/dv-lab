- `prepareDispatch` writes that baseline into the stage request's `cancellationBaseline` inside its `FOR UPDATE` transaction (the stage digest covers only `{ eventId, ...payload }`, so it stays valid), and dispatch continues with the request that carries it; `verifyCancellation` and a restart through `storedGoogleResult` then find the baseline.
