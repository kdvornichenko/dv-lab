## Сигнатуры и передача следующим планам

- Date-sensitive schemas требуют `expectedDefaultTimeZone`. Response lesson/block/series имеют immutable `timeZone`.
- Series response требует `referenceOccurrence: {originalOn,actualStartsAt,ruleStartsAt:null|string}|null`; wire instants — ISO.
- `readWindow(executor,from,to,context:TeacherTimeContext)` возвращает blocks/series/defaultTimeZone/asOf; `readWeek(executor,monday,context)` добавляет start. Повторного чтения settings нет.
- Rows uses UTC edge dates ±1 день для candidate selection; exact filtering остаётся в core. Moved owners грузятся независимо.
- `seriesReferenceExceptions(executor,seriesIds)` загружает полные exceptions показанных series, включая reference вне недели. Create existing использует тот же owner.
- `toWireSeries(rule,reference:ReturnType<typeof nextSeriesReference>)` требует реальный reference. Plan06 обновляет оставшиеся mutation callers.
- `createLesson(db,accountId,input,now?)`, `moveLesson(db,accountId,id,input,now?)`, `moveOccurrence(db,accountId,seriesId,originalOn,input,now?)` блокируют account первым. Один now передаётся в context.
- Creation inserts записывают current default. Moves меняют только startsAt/exception, сохраняя stored zone. Canonical identity входит в existing weekly duplicate lookup.
- `ChangeFailure` включает default_time_zone_changed и nonexistent_local_time. HTTP возвращает 409 со stale copy C31 либо 400 для gap.
- Routes уже вызывают `moveSeries/endSeries(db,accountId,id,input)`; их реализацию завершает Plan06. API convergence до этого не заявляется.
- Cancel/restore/mark сохраняют прежние guards, no-store/session/teacher/Origin policy. D-17 past move остаётся доступным.
