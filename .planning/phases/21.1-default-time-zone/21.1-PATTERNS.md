**Analog:** `packages/core/src/schedule.ts`. Применить к core `zoned.ts`, `schedule.ts`, `balance.ts`, условному `schedule-series.ts`; web formatters/preview берут только принцип вызова pure owner. Они не копируют recurrence/cut/accounting.

**Imports** (строка 1): внутренний относительный импорт с `.ts`; core не импортирует API, contracts, БД или Node. API и web используют публичный `@dv-lab/core` barrel.

**Переносимый pattern:** чистые типизированные аргументы, discriminated result, стабильный ref. При выделении `schedule-series.ts` переносить ответственность строк 330–428 целиком, а не копию алгоритма; `occurrenceAt`, `hasOccurrences` и остальные owners вызывать. Публичный экспорт остаётся у core. Не создавать обратный runtime import `schedule.ts → schedule-series.ts → schedule.ts`: barrel экспортирует оба владельца.

**Адаптация:** `SeriesRule`, `SingleLesson`, `CutLesson` получают `timeZone`; `originalOn` остаётся natural date старого rule. New rule после cut получает current main, detached lessons — old rule zone. Равные weekday/time при другой зоне не означают no-op. Cut/end получают явный account context по RESEARCH; граница UI переводится в instant, затем в old natural cutoff. Форму успешного результата выше сохранить.

**Имена:** в frozen source окно раскрывает `scheduleWindow` (205–239), а не отдельный export `occurrencesInWindow`. Термин из RESEARCH не повод создать второй resolver. `nextLessons` (270–304), `occurrenceAt` (147–166), `seriesStart` (143–145) остаются единственными owners. Старые глобальные Vietnam calls и остановку поиска на DST gap не копировать.

**Validation / errors:** входные strings валидирует contracts; core возвращает domain result. Новый ручной gap и fold/recurrence policy взять точно из RESEARCH §5; не переносить старый two-pass `zonedInstant` как доказанную DST-реализацию. HTTP и auth core не принадлежат. Проверки — P5.

export async function savePaysSoonLessons(
	executor: DbExecutor,
	accountId: string,
	paysSoonLessons: number
): Promise<number> {
	const [row] = await executor
		.insert(teacherSettings)
		.values({ accountId, paysSoonLessons })
		.onConflictDoUpdate({
			target: teacherSettings.accountId,
			set: { paysSoonLessons, updatedAt: sql`now()` },
