## Решения

- Сохранённые instants и creation zones не меняются при выборе default zone.
- Единственный core owner выбирает reference occurrence. API передаёт его явно; UI использует natural rule instant.
- Pays soon публикует только изменённое поле. Независимый ответ не откатывает новую default zone.
- Weekly dedup включает canonical creation zone. Алиасы одной зоны не создают второе правило.
- Migration предшествует согласованному переключению API/web. После non-Vietnam writes старый runtime несовместим.
