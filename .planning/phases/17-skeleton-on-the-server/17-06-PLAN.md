deploy/postgres/ensure-db.sql — начать с примера ensure-db.sql из Code Examples и привести к раскладке домашнего сервера (решение владельца 4). Имена ролей фиксированы в SQL (dvlab_migrator, dvlab_app), параметры через переменные psql: db_name, migrator_password, app_password. Порядок:
1. \set ON_ERROR_STOP on.
2. Создать роль dvlab_migrator, если её нет: LOGIN NOSUPERUSER NOCREATEDB NOCREATEROLE NOREPLICATION NOBYPASSRLS с паролем из переменной (format с %I и %L и \gexec). Так же dvlab_app.
3. На каждом запуске ALTER ROLE обеих ролей с паролем из переменных (ротация) и ALTER ROLE обеих ролей SET search_path = public, extensions.
4. Создать базу :db_name с OWNER dvlab_migrator и ENCODING UTF8, если её нет.
5. REVOKE ALL ON DATABASE от PUBLIC; GRANT CONNECT, TEMPORARY ON DATABASE роли dvlab_app.
6. \connect :db_name.
7. CREATE SCHEMA IF NOT EXISTS extensions AUTHORIZATION CURRENT_USER (суперпользователь); GRANT USAGE ON SCHEMA extensions обеим ролям; CREATE EXTENSION IF NOT EXISTS pg_trgm WITH SCHEMA extensions. Расширения создаются только здесь, под суперпользователем (D-13).
8. GRANT USAGE ON SCHEMA public роли dvlab_app.
9. ALTER DEFAULT PRIVILEGES FOR ROLE dvlab_migrator IN SCHEMA public: SELECT, INSERT, UPDATE, DELETE ON TABLES и USAGE, SELECT ON SEQUENCES роли dvlab_app.
