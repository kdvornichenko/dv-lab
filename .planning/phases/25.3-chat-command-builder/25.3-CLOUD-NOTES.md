## Отклонения от планов (проверить)

1. **Переключатель push ассистента выключен по умолчанию.** Дизайн противоречит себе: README `SettingsNotifications` (v124) говорит «off by default», code-sync 158(d) говорит «on by default». Выбран README (осторожнее: push на каждый ответ без просьбы не уходит). Если нужен on, правится `default(false)` в схеме и `notifyAssistant: false` в `NOTIFY_SETTINGS_DEFAULT`.
2. **Сигнал `info` опирается на `chat_conversations.updated_at`**: чтобы он менялся при окончании ответа, `finish()` в `runs.ts` теперь обновляет `updated_at` разговора. Это меняет порядок в списке разговоров (ответ поднимает разговор наверх). Проверить разделы `chat-api.mjs` про порядок и `updatedAt`.
3. **Сценарий 8 приёмки (`command_too_large` по маршруту) недостижим**: ни один разрешённый инструмент не strict, превышение проверяется синтетическим набором в `chat-tools-schema.mjs`.
4. **Тесты ожиданий Fable** в `chat-config.mjs`, `chat-api.mjs`, `chat-web.mjs` переписаны под три модели; в гонках бюджета `chat-api.mjs budget` вместо Fable Opus (резерв 0.82 USD), лимит гонки 1.00 USD.
5. Названия полей usage из SDK 0.135.0 (`cache_creation.ephemeral_5m_input_tokens`, `output_tokens_details.thinking_tokens`) взяты из AI-SPEC и читаются защитно (`Reflect.get`); подтвердить по типам после установки SDK.
6. `ChatProvider` держит один `useChat` над страницами; `ChatScreen` берёт состояние из контекста, на странице `/chat` вызывает `adopt(conversationId, startNew)`; в `useChat` адрес меняется только на `/chat` (`onChatPage`). Это самое рискованное изменение: проверить все разделы `chat-web.mjs` и ссылки `?c=`, `?new=1&student=`, `?review=1`.
7. В `useChat` резервная замена адреса (`fallbackId`) теперь не трогает адрес, если в нём уже есть `new` или `c`, отличный от выбранного: иначе при переходе по ссылке `/chat?c=<id>` внутри приложения резерв перезаписал бы запрошенный разговор до `adopt`.
8. Отступы `app-shell.tsx` после обёртки `<ChatProvider>` не выровнены: `yarn format`.
9. Тост 158(b) не строится (его заменяет пузырь звезды, 160c); пилюля `LocalData` по центру карточки не правилась.
