## Чего в дизайне нет (нужно от Design dude, до планов 25.3-07 и 25.3-08, задача 2)

1. **Экран конструктора команд в Settings → Assistant** (список команд, редактор, выбор инструментов с счётчиками «N of 20 strict, N of 24 optional, N of 16 union», редактор блоков, переключатель «Needs a student», архив и возврат). Ближайший образец, не замена: `SettingsPrompts` (поле запроса, счётчик, Save, Discard, конфликт ревизии). Состояния, которые нужны: пустой список, ошибка сохранения, имя занято или зарезервировано, лимит превышен (Save выключен с причиной), конфликт ревизии, архивная команда.
2. **Блок ответа команды с Copy** (`command`: имя блока, текст или список, Copy на каждом блоке, строка «withheld» для удержанных строк, подпись команды и ревизии). Ближайший образец: блок дат с Copy `ChatLessonDates` (code-sync 83). Нужны тексты, состояния «copied» и пустой блок.
3. **Тексты, которых нет в README:** подписи полей конструктора, текст отказов `command_unavailable`, `command_too_large`, `command_rejected` (сейчас у `refused` в `ChatNotices` нет таких кодов).
4. **Открытый вопрос владельца из README `AssistantStar`:** нужен ли другой способ открыть панель, когда звезда далеко от взгляда (строка Chat в сайдбаре ведёт на страницу чата). Не блокирует планы: строится то, что записано.

## Правила для планов с UI

- План 25.3-07 и задача 2 плана 25.3-08 (блок `command`) помечены «ждёт выгрузки дизайна»: они стоят до появления в дизайне компонентов пунктов 1 и 2. Планы 25.3-09…12 опираются на README и code-sync выше; перед ними локальная сессия сверяет `VERSION` дизайна с v128.
- Только Base UI и готовые компоненты варианта A, без своих обёрток; английский текст интерфейса; компактно, под экран ноутбука; одно действие — одна кнопка.
- Проверка в браузере: пути пользователя на 375 и 1280 px, светлая и тёмная темы, Firefox отдельно для затухания и перетаскивания звезды.

## AssistantStar: исходник

Файл `apps/web/components/app/assistant-star.tsx` — анимированный персонаж владельца (`FrostCloud`), переименованный в `AssistantStar` без правки формы, палитры и движка анимации: префикс классов и переменных `ui-star`, `style href="ui-assistant-star"`, префикс id `as`, подпись по умолчанию про жёлтую звезду; комментариев нет. Форма и палитра — по выгрузке Design dude, сейчас в компоненте облако как заглушка. Жёлтая пятиконечная звезда с высокими овальными глазами, токены `--star-top`, `--star-bottom`, `--star-edge`, `--star-eye`, `--star-glint`, `--star-shadow`, перетаскивание, поле ввода и состояния из дизайна v128 в этот файл не входят (план 25.3-11). Компонент нигде не подключён, кнопка чата не менялась.
