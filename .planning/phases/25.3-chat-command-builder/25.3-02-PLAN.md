`tool-registry.ts`: (1) `allowedCommandTools(entries)` — записи с `effect` `read` или `show` и без `review: true` (D-14); (2) `commandTools(entries, names)` — записи реестра по именам в порядке реестра (детерминированные байты запроса), неизвестное или не разрешённое имя бросает ошибку с этим именем; (3) `commandSchema(blocks)` по образцу AI-SPEC §4b: на входе блоки с `key`, `name`, `format`; на выходе `{ schema, input }`: `schema` — `type: 'object'`, `properties` `block_N` (`string` или `array` из `string`, `description` — имя блока), `required` — все ключи, `additionalProperties: false`; `input` — `z.strictObject` с теми же ключами и пределом длины текста блока (`BLOCK_TEXT_MAX`, константа модуля; пределы длины в схему API не попадают); (4) `strictBudget(tools, format?)` — считает `strict` инструменты, необязательные параметры (свойства вне `required`) и union-параметры (массив в `type` или `anyOf`) только у strict-схем и у схемы ответа целиком, возвращает `{ strict, optional, union }` и пределы 20, 24, 16 как константы рядом. Подсчёт один в один с `shape()` скрипта.

`chat-tools-schema.mjs`: убрать `shape()` и константы пределов, импортировать `strictBudget` из реестра; проверки наборов `CHAT_TOOLS`, `ESSAY_TOOLS`, `REVIEW_TOOLS` по-прежнему в пределах; добавить проверки: набор всех разрешённых инструментов (`allowedCommandTools`) плюс схема из восьми блоков — в пределах; синтетический набор из 21 strict-записи — вне пределов (`strictBudget` видит превышение); в схеме ответа нет `anyOf`, `null`, `minLength`, `maxLength`; вымышленная команда `/homework` из AI-SPEC §5 (`student_notes`, `lesson_dates`; блоки Exercises list и Message text) — печатает схему целиком для чтения владельцем (D, «Schema privacy»).
