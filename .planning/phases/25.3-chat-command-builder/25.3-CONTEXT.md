## Locked Decisions

### From ROADMAP and AI-SPEC (not reopened)
- **D-01 (R, A C-1, D-AI-1)** A command that generates its answer returns blocks through `output_config.format`; a command that reads records returns blocks through `show` tools. One turn may read first (read and show tools), then answer with the schema.
- **D-02 (R, A C-2)** `tool_choice` stays `auto`.
- **D-03 (R, A C-3)** One request holds at most 20 strict tools, 24 optional and 16 union parameters, the response schema included. `strictBudget(tools, format)` in `tool-registry.ts` is the one counter: save is rejected with the counts, the builder shows "N of 20 strict, N of 24 optional, N of 16 union" and disables Save with a reason, the turn start checks again with a refusal block and no API call. `chat-tools-schema.mjs` imports it instead of its own `shape()` copy.
- **D-04 (A D-AI-2)** Command blocks go through a soft gate: links and plain numbers are allowed; a line with a money sign or a number next to balance, payment or lessons-left words is withheld. Text outside blocks keeps `checkSentence`.
- **D-05 (A §4)** `commandSchema(blocks)` builds the JSON Schema and the zod object from one block list: keys `block_1…block_N`, all required, no `anyOf`, no nullable, block names only in `description`; templates and rules go into the user message. JSON is parsed only on `end_turn`; `max_tokens`, `refusal` and validation failures give no command blocks. A typed `BadRequestError` on a command turn ends it with a dedicated refusal code.
- **D-06 (R, A C-6)** Cache TTL stays 5 minutes. Log and store the usage fields from A §4b (5m/1h split, thinking tokens, conversation, command name, request index); cache `diagnostics` on the dev stack during measurement.
- **D-07 (R, A C-7)** `@anthropic-ai/sdk` 0.133.0 → 0.135.0, exact version in `package.json`; `yarn.lock` is updated by the local session.
- **D-08 (R)** ChatPanel (design v123, code-sync 157) and closed-chat signals (v125, code-sync 158) are in the phase. Assistant star `AssistantStar` (design v128, code-sync 159, 160) replaces the header chat button; design files are outside the repository, see `25.3-UI-SPEC.md`; plans with UI wait for the design export.
- **D-09 (A)** Checks use one made-up command `/homework` (A §5); the owner fills real Edvibe templates in Settings.
