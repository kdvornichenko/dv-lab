# 25.3-06 — Api: push ассистента (закрытый чат) и настройка notify_assistant

<objective>
Серверная часть сигналов закрытого чата (code-sync 158, части (c) и (d), D-08): push при готовом ответе или ожидающем решении и общий переключатель аккаунта. Вид переключателя и точки — 25.3-10, панель — 25.3-09, звезда — 25.3-11 и 25.3-12. Тост 158(b) не строится (code-sync 160c).

Решения по своему усмотрению: событие — окончание хода в `finish()` (`runs.ts`) через необязательный обработчик, переданный при создании ходов из `server.ts` (в тестовом окружении планировщик push не создаётся, обработчик пуст); вид события «Waiting for your decision», если в блоках завершённого сообщения есть предложение в состоянии `proposed` (`calendar_proposal`, `change_proposal`, как считает `waiting` в `conversations.ts`), иначе «Reply is ready»; ссылка — `chatLink(conversationId)` в `contracts/links.ts`, равная `/?chat=<id>` (разбирает оболочка web, 25.3-09: панель от 1024px, страница `/chat?c=<id>` ниже); присутствие — любое свежее сигнал-присутствие этого устройства (`isPresentAnywhere` в `presence.ts`), потому что сигнал шлёт только вкладка на переднем плане; повторный push по тому же разговору заменяется по `tag`.

Executor model: opus.
