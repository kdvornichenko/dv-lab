<objective>
Экран конструктора команд (D-16..D-19, D-03, D-14) в Settings → Assistant рядом с `Command prompts`. Данные и правила — api (25.3-03). Вид — только из дизайна: пока Design dude не нарисовал конструктор (UI-SPEC, пункт 1), план стоит; готовые компоненты варианта A (`SettingsPrompts`: поле, счётчик, Save, Discard, уведомление о конфликте; `FormFields`; `Switch`; `Select`) берутся как есть.
