# Phase 22: сверка планов с кодом после 25.1

Дата: 2026-10-13. Ветка `gsd/phase-22-chat-replan`, HEAD `8e3f1a1` (код 25.1 Google Calendar Core). Планы 22 не менялись, ниже только расхождения и правки.

## Сводка

1. Планы 22 писались под Phase 25 (архив) и pin `913fc5a`: везде стоит «rebind final24/25», ссылки на `25-RESEARCH`, предложенные `resolveProviderTarget` и origin-aware admission. Этого нет. Реальные владельцы теперь: `calendar/projection.ts`, `calendar/read-model.ts`, `calendar/commands.ts`, `calendar/journal.ts`, `schedule/command-plan.ts`, `schedule/cut-apply.ts`, `schedule/inbound-apply.ts`.
2. Главный конфликт: начавшийся урок нельзя перенести и отменить (`history_only`). «Didn't happen» (в планах это отмена через Google) и «moved to <date>» учитель обычно пишет после урока, и именно для таких уроков api откажет. Без решения владельца 22-07 и 22-14 исполнять нельзя.
3. Отметки (`done`, `no_show`, `none`) пишутся локально и только у начавшихся уроков, Google их не трогает. Revision у `lesson_marks` по-прежнему нет, план 22-04 нужен. Писателей два: `marks.ts` и `cut-apply.ts` (`series.ts keepCutLessons` больше нет).
4. Обновление открытых экранов: опрос ревизии синхронизации (`useGoogleSync`, раз в 20 с) обновляет Today и Schedule только после команд Google. Запись отметки ревизию не двигает. Механизма между вкладками для локальных данных нет, поэтому часть 22-03 остаётся, но её стоит строить поверх `register`/`store.refresh`, а не новым `data-changes.ts`.
5. Команды уроков из чата: приём онлайн (Google читается при admission), ответ 202 с `{commandId, statusUrl}`, нужен `expectedVersion` из версии события в проекции, любая незавершённая команда аккаунта даёт `command_pending`, вне окна 8/53 недель приходит `outside_sync_window`.
6. Политика проверок: каждый план 22 начинается с e2e-сценария против `https://dv-lab.dev` (прод). Это противоречит 25.1 D-11 и правилу владельца (новых тестов нет, приёмка скриптами `scripts/dev-checks`, браузером и логами, прод для проверок не трогается).
7. Мелкое: `drizzle.config.ts` перечисляет файлы схемы явно; в compose у api уже есть `env_file`; pg-boss есть только внутри календаря; UI привязан к дизайну v40, а 25.1 сделана по v55.
