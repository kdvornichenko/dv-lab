# 22-13 — Ответы модели: цикл Messages, поток, Stop

<objective>
Подключить модель: свободный текст в чате получает потоковый ответ, инструменты читают записи и пишут через исполнителя 22-09, расход идёт через бюджет 22-12 (SC1, SC5, CHAT-09, CHAT-11).

Executor model: opus (платный цикл, восстановление, инструменты).

Purpose: без этого CHAT-07 и свободные формулировки не работают.
Output: таблица ходов с REVOKE, обёртка провайдера, инструменты, проверка публикации, бегун ходов, маршруты потока и Stop, сборка в `server.ts`, клиент SSE в `api-client.ts`, поток в /chat, проверки на заглушке провайдера.

Решения плана:
- Журнала событий на аккаунт с курсором нет (В7). Поток — на ход: `GET /chat/turns/:id/stream` (SSE) отдаёт снимок сохранённого состояния хода и затем живые события из памяти процесса; каждое событие сначала записано в базу (предложение дописано в тело ответа, блок — в `blocks`), потом отправлено. Переподключение = новый снимок. Один активный ход на разговор (частичный уникальный индекс).
- Очереди pg-boss для чата нет: единственный PgBoss живёт в `calendar/worker.ts` и создаётся только при включённом Google; ход выполняется в процессе api как асинхронная задача, состояние в базе, при перезапуске — `interrupted` без повтора. Чат не зависит от `config.calendar.enabled`.
- Проверка публикации делается здесь, а не в 22-14: без неё нечего показывать в потоке.
</objective>
