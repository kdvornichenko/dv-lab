## Отклонения и решения, которые стоит проверить

1. Время сообщений теперь всегда `HH:MM` в основном поясе и больше не уходит в день недели или дату для старых сообщений (раньше это подмешивала функция списка чатов). Для списка `conversationTime` не менялся.
2. Копирование в буфер: общий хук `useCopy`, на отказ тултип `Could not copy`. Диалог Count lessons тоже перешёл на него (в задании только блок).
3. Упоминания в ответах раскладываются плагином по позициям в markdown-исходнике, а не подменой исходника ссылками: смещения сервера остаются верными. Диапазон, который попал внутрь одного узла `strong`/`em`, работает, диапазон через границу разметки не рисуется.
4. `StudentMention` лежит в `chat/_components`, не в `components/app`: он тянет `BalanceFact` и `NextLessonFact` чата и нужен только чату.
5. Карточка упоминания не рисует строку частичного охвата: у `ChatStudentFacts` нет поля охвата.
6. Ссылка «Pays soon» ведёт в профиль, хотя имя тоже ведёт в профиль: так в таблице README AgentLinks.
7. Ссылки на профиль с `entry`, `section`, `tab=payments` собираются, но сами метки на вкладках профиля делает исполнитель страниц студентов.
8. Блок `action_link` пока не рисуется: `Block()` в `messages.tsx` теперь возвращает `null` для неизвестных типов (раньше любой неопознанный блок рисовался как «Reply interrupted»). Нужен case для `action_link`.
