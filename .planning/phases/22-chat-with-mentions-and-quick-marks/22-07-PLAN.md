# 22-07 — Комментарии урока

<objective>
Комментарии урока (CHAT-04) по решению В4 бывают только у начавшегося урока. Ключ комментария стабилен при переносе (22-01). Разрез серии (22-18) начинается после последней удерживаемой даты; этот план добавляет в удерживаемые даты (`heldSeriesDates`) вхождения с неотозванными комментариями, поэтому начавшееся неотмеченное вхождение с комментарием остаётся в старой серии со своим ключом. Единственный случай смены ключа — `insertDomain` при окончании серии переносит перенесённое вхождение хвоста в одиночный урок; там комментарии идут вслед за отметкой.

Executor model: sonnet.

Purpose: чат (22-09) пишет комментарий в транзакции с квитанцией и отзывает его по Undo; учитель видит комментарии в диалоге урока.
Output: порт комментариев, маршруты чтения и отзыва, перенос в `insertDomain`, показ в `LessonDetails` для обоих диалогов, проверки.
</objective>
