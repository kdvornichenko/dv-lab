# 22-18 — Серия с начавшимися вхождениями: «all», «this and following» и правки серии из Google

<objective>
Распространить правило В1 на серию. Решения владельца 2026-10-13: при «all» начавшееся вхождение без done переносится вместе с серией (вопрос 6); входящая серийная правка из Google для начавшихся вхождений без done применяется как для будущих (вопрос 4). Основа — 25.1 D-21 («all» переносит каждое вхождение, которое в будущем или без отметки; отмеченные остаются на старом времени со своей отметкой и остатком; механику выбирает планировщик).

Executor model: opus (правило разреза, входящее применение, ключи вхождений).

Механика (решение планировщика):
- Якорь `allFrom` = первая дата серии `d`, для которой `d >= max(startsOn, первая дата окна синхронизации в поясе серии)` и `d` позже каждой удерживаемой даты. Удерживаемая дата — `original_on` вхождения с отметкой `done` или `no_show` (22-07 добавляет вхождения с комментариями). Нет такой даты (серия кончилась) — `null`.
- Разрез один, поэтому вхождения с отметкой не получают новый ключ: отметка, остаток, комментарии и квитанции чата (22-09) остаются на своём ключе (AGENTS.md, «База»). Неотмеченные вхождения раньше последней отметки остаются на старом времени — следствие одной точки разреза.
- `no_show` при «all» остаётся на старом времени. Перенос `no_show` вместе с серией потребовал бы переноса строки отметки, комментариев и квитанций на ключ новой серии; 25.1 D-21 оставляет отмеченные вхождения на месте. Вопрос владельцу записан в `22-REPLAN-RESULT.md`.
- `endSeriesAt` (End series) не меняется: дата окончания по-прежнему не раньше сегодня.
- `lessonActions.series` не меняется: Today переносит начавшийся урок только областью `one` (решение владельца, вопрос 10). Области серии для начавшегося вхождения в Schedule показывает 22-02 по `allFrom`.

Purpose: «All lessons» в календаре и в чате (22-08, 22-10) переносит и сегодняшний начавшийся урок, а правка серии в Google перестаёт расходиться с сайтом для начавшихся неотмеченных уроков.
Output: правило якоря и разреза в core, отказ по удерживаемым датам и окну при приёме, `allFrom` в контексте серии недели, входящий путь по новому правилу, обновлённые проверки, скрипт приёмки, AGENTS.md.
</objective>
