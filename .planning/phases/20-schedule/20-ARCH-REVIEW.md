# Архитектурный осмотр — фаза 20

Дата: 2026-10-10. Область: `packages/db` (schema), `packages/core`, `packages/contracts`, `apps/api` (routes, cards), `apps/web` (schedule, students). Источник: gsd-arch-scan (--auto, владелец не смотрел).

## Находки

1. **Правило видимости вхождения** (Strong). Отбор «дата серии — вхождение, если исключение не говорит иного» записывается в SQL недели, SQL следующего урока и в мутациях; фаза 21 станет третьим читателем. D-16 добавляет скрытую историю (исключения за `ends_on`, moved-исключения после разреза), и без одного владельца условия размножатся по запросам. Рекомендация: в этой фазе.
2. **Производные поля карточки** (Strong). `nextLessonAt` проходит через `toCardRow`, `toStudentDetail`, `toDetail`, `createCard`, `listCards`, `updateCard`, archive, restore, `setOpeningBalance`. Рекомендация: в этой фазе, один владелец производных фактов (остаток и следующий урок) в модуле карточек.
3. **«Сегодня» в трёх зонах** (Worth exploring): `localIsoDate`, `latestPaymentDate`, зона Вьетнама. Рекомендация: отложено до фазы 21; код расписания берёт «сегодня» только через `core` и `SCHEDULE_TIME_ZONE`.
4. **Диапазон длительности урока в шести местах** (Speculative). Отложено вместе с находкой 4 фазы 19; схемы `contracts` берут `LESSON_MINUTES_*`.
5. **Заготовки ответов роутеров** (Speculative). Отклонено: третья однострочная копия дешевле общего модуля.

## Для планировщика

- Видимость вхождения (включая скрытие истории по D-16) принадлежит только `core/schedule.ts`; `api` загружает надмножество строк одним загрузчиком для окна недели и для «от сейчас», фильтров видимости в SQL не дублировать.
- Производные факты карточки (остаток, `nextLessonAt`) считает один владелец в `apps/api/src/cards`, его вызывают `listCards` и `toDetail`; в плане решить, входит ли `nextLessonAt` в `StudentDetail`.
- Условия отложенных: код расписания не использует `localIsoDate` и `latestPaymentDate`; новые zod-схемы импортируют `LESSON_MINUTES_*`.
- D-16 главнее исследования: Pattern 2 шаги 5-6, Restore и End series в Pattern 3 и допущение A3 в 20-RESEARCH.md удаляют строки, считать их неверными.
