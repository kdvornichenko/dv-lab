- **E2E-2, язык.** Файлы `.mjs`, как scripts/dev-checks: одна зависимость, без отдельного tsconfig и `@types/node`. Типы не проверяются намеренно, качество держат prettier, knip и сам прогон. Это записывается в SUMMARY.
- **E2E-3, пакет.** Один пакет `@playwright/test`, точная версия. Рекомендация 1.63.0 (2026-09-04): та же версия playwright-core, что у scripts/dev-checks/web.mjs (через PLAYWRIGHT_CORE из соседнего репозитория), и её браузер chromium-1243 и chromium_headless_shell-1243 уже лежат в `~/Library/Caches/ms-playwright`, скачивать нечего. Вариант 1.64.0 (latest, 2026-10-07, барьер 1440 минут проходит) требует chromium-1248: `yarn playwright install chromium` в кэш вне репозитория. В 1.63.0 у трёх пакетов (`@playwright/test` → `playwright` → `playwright-core`) нет install-скриптов и необязательных зависимостей; браузеры при установке не качаются. Выбор делает владелец на задаче 0.
- **E2E-4, CI.** В job Verify e2e не добавляются: им нужен dev-стек с настоящей базой, учётная запись учителя из локального `.env` и браузер. `.github/workflows/ci.yml` не меняется. `yarn install --immutable` в CI и сборка образов (turbo prune оставляет devDependencies корня) ставят три пакета без браузера — принято.
- **E2E-5, dev-стек.** Тесты идут против уже запущенного стека (`yarn test:e2e` = `node scripts/dev-checks/wait-dev.mjs up && playwright test`), без `webServer` в конфиге: api запускается с убранными DATABASE_URL и MIGRATOR_DATABASE_URL окружения (EXECUTOR-RULES, правило 5), эту логику конфиг не повторяет.
- **E2E-6, артефакты и секреты.** `outputDir` — подпапка `STATE_DIR/e2e-results` (STATE_DIR из scripts/dev-checks/paths.mjs, папка 0700 вне репозитория), и только подпапка: Playwright очищает outputDir в начале прогона, а в самом STATE_DIR лежат пароли фикстур api.mjs для dvlab_test; `trace: 'off'`, `video: 'off'`, `screenshot: 'only-on-failure'`, `reporter: 'list'`. Трасса записала бы тело запроса входа с паролем, html-отчёт и скриншоты содержат настоящие строки dvlab_dev. Файл сессии и снимок настроек тоже в STATE_DIR; teardown выходит из сессии и удаляет файл сессии. `.gitignore` получает `/test-results` и `/playwright-report` как страховку. `.dockerignore` не меняется: turbo prune копирует в образ только workspace, артефакты лежат вне репозитория.
- **E2E-7, фикстуры.** Карточки `Alex Example 2182` … `2189`. Номера 2180 и 2181 заняты разделами today-marks и today-payment ledger-web.mjs (21-11); уборка по префиксу `Alex Example 218%` уберёт и их остатки, что допустимо в волне 12; одновременно с ledger-web.mjs e2e не запускаются.
