## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Составные команды в worktree | Хук изоляции отказывает на heredoc, переменные, `cd`, `git -C`, `&&` с git | advisory | простые команды, пути литералами, файлы через Write и Edit |
| gsd-tools из вложенного каталога | `query commit --files` и `state.record-session` из каталога фазы молча пропускают файлы | advisory | вызывать из корня worktree, после коммита проверять `git status` |
| Dispatch без изоляции | Хук блокирует исполнителей, если не запущен dispatch | blocking | перед каждой волной `bash scripts/gsd/dispatch.sh 21`, не запускать `dispatch-isolation --json` |
| Параллельные yarn test и build api | `yarn test` очищает dvlab_test, tsdown стирает `apps/api/dist` | blocking | не больше одного плана со сборкой api и одного web-плана на волну |
| next dev создаёт apps/web/AGENTS.md | файл не коммитить | advisory | удалять перед коммитом |
| Реальные данные в dvlab_dev | в базе реальный импорт vault | blocking | проверки меняют данные только у карточек `Alex Example 21*`, в SUMMARY только «показывает N строк» |
