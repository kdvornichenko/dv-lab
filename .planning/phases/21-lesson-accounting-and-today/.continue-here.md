## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Dispatch без изоляции | Хук блокирует исполнителей, если не запущен dispatch | blocking | перед каждой волной `bash scripts/gsd/dispatch.sh 21`, не запускать `dispatch-isolation --json` |
| Параллельные yarn test и build api | `yarn test` очищает dvlab_test, tsdown стирает `apps/api/dist` | blocking | не больше одного плана со сборкой api и одного web-плана на волну |
| Реальные данные в dvlab_dev | в базе реальный импорт vault | blocking | проверки меняют данные только у карточек `Alex Example 21*` (фикстуры плана 21-18: 2182-2189), в SUMMARY только счётчики |
| Составные команды в worktree | Хук изоляции отказывает на heredoc, переменные, `cd`, `git -C`, `&&` с git | advisory | простые команды, пути литералами, файлы через Write и Edit; не заходить в каталог фазы командой cd |
| Забытые dev-серверы | остаются `yarn workspace @dv-lab/api dev --watch` и next dev на портах 3000 и 4000 | advisory | после волны `node scripts/dev-checks/wait-dev.mjs down`, при DEV_DOWN_FAIL найти процесс через lsof и остановить |
| next dev создаёт apps/web/AGENTS.md | файл не коммитить | advisory | сохранить неотслеживаемым; удаление не разрешено |
| Раздел settings в ledger-web.mjs | меняет порог настоящего учителя на время прогона | advisory | не запускать параллельно с другими проверками порога |
