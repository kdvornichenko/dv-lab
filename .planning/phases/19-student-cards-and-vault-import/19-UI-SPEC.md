## Spacing Scale

Identical to the baseline [18]: 4 / 8 / 16 / 24 / 32 / 48 / 64 (`xs` to `3xl`), no half steps, no `3`, `5`, `7`, `28` step classes in new or edited code. Dialog form groups `gap-4`; field label to input `gap-2`; two-column field rows `grid gap-4 sm:grid-cols-2`; panel content padding `px-4 pb-4`; page block gap `gap-4 md:gap-6`; table cell padding `px-4 py-2`.

Exceptions (component dimensions only): control heights 28 / 36px, `Avatar` 28px, status dot 8px with a 16px invisible hit area (`before:-inset-2`), dialog widths 400 / 540px, Textarea `min-h-16` (64px) for a vocabulary note and `min-h-32` (128px) for a markdown editor.

## Typography

Same four sizes and two weights as the baseline [18]: Display 22/28 (600, `text-display`), Heading 16/22 (600, `text-title`), Body 13/20 (400, `text-body`), Caption 12/16 (400, `text-caption`). No `text-subtitle`, `text-sm`, `text-xs`, `font-medium`.

| Role | Where in this phase |
|------|---------------------|
| Display | `h1` of `/students` ("Students") and `/students/[id]` (the card name; truncates, wraps on narrow widths) |
| Heading | Dialog titles, `Panel` titles (Details, Opening balance, Account, the six note titles, ReadError title) |
| Body | Everything else: table cells, field labels (muted), values, markdown paragraphs, header summary line, tab labels, buttons |
| Caption | Field helpers and errors, hints (opening balance hint, prefill hint), tooltip-adjacent secondary text, counts under toolbars when secondary |

Markdown inside sections never introduces new sizes: `h1` and `h2` render as `text-title` 600, `h3` to `h6` as `text-body` 600 (DR-1), everything else `text-body` 400, inline and block code as `font-mono` (JetBrains Mono Variable) at `text-body` 400. Money, dates and lesson counts use `tabular-nums`.

## Balance and Money Display Rules

All formatting goes through `packages/core` [D-06]; the UI passes stored values and renders the returned strings.

| Rule | Decision |
|------|----------|
| Stored value | Minutes; **minutes are never shown**: not in cells, tooltips, `aria-label`s, toasts or errors |
| Lessons | `minutes / default_lesson_minutes` of the card, rounded half away from zero to two decimals, trailing zeros removed: 3, 1.5, 0.25, 0.33. Decimal separator is a dot. Negative values keep the minus sign |
| Label | "{n} lessons"; singular "1 lesson" only for exactly 1. In table cells and the Details/Balance rows the bare number or "{n} lessons"; in the header "{n} lessons left" ("1 lesson left") |
| Opening balance not set | Everywhere a balance would show: "Set opening balance". List: muted plain text. Header: `Button variant="ghost" size="compact"` "Set opening balance" that switches to the Overview tab and focuses the "Lessons left" field. Imported payments never affect the shown number before the opening balance is set |
| Opening balance input | "Lessons left" accepts 0 or more, up to two decimals, dot or comma as the separator, spaces ignored; stored as `lessons x default_lesson_minutes`. Negative input is rejected in this phase [default]. "As of" defaults to today and may be any past or present date |
| Money | `Intl.NumberFormat('en-US', { style: 'currency', currency, currencyDisplay: 'narrowSymbol', minimumFractionDigits: 0 })` ("₽1,500", "₽1,500.50", "₸90,000"). Minor-unit digits come from `Intl` for the currency (D-07). Amount without currency: the number with grouping and up to 2 decimals plus the muted words "No currency" |
| Money input | One text field, `inputMode="decimal"`, digits with one dot or comma separator, spaces ignored, no thousands separators, no currency adornment (the currency is its own `Select`) |
| Lessons prefill (Record payment and Assign) | Only when a rate is set and the payment currency equals the rate currency: `amount / rate`, rounded to two decimals, shown as a lessons string. Recomputed on amount or currency change until the teacher edits the Lessons field; after that never overwritten. Otherwise empty. Empty is valid and means "Not counted" (zero minutes). Never `max(1, …)` |
| Dates | `Intl.DateTimeFormat('en-US', { dateStyle: 'medium' })`; payment dates are calendar dates (`YYYY-MM-DD`), formatted without time-zone shifts. Payment date may not be in the future [default] |

## Interaction Contract

- **Tabs.** Switching never discards an open note editor's text while the page stays mounted; leaving the page does.
- **Navigation.** List row, name link and the back button are the only navigations. After archive or restore the profile stays open and the header swaps its action; after creating a card the app opens it.
- **Unassigned count.** The tab count updates after Assign and after deleting an unassigned payment.
- **Roles.** Every route here is teacher-only [D-27]; a student account keeps landing on `/` (baseline redirect). A 403 or 401 from these routes behaves as in the baseline (redirect to `/login`).
- **Narrow widths.** Page padding 16px; tables scroll horizontally inside their frame only; header actions wrap; dialogs keep `w-[calc(100%-2rem)]`; the two-column field rows collapse to one column below 640px; the Overview grid collapses below 1024px. Phone layout polish stays in phase 23.
- **Motion and theme.** Registry defaults only; every screen and dialog is checked in light and dark.
- **Accessibility.** As in the baseline conventions; this phase adds nothing beyond status-dot tooltip plus `aria-label`, icon-only button tooltips plus `aria-label`, and the `aria-label`s listed in the Copywriting Contract.
